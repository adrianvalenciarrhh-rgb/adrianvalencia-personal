# Web personal de Adrián Valencia — sitio estático
HTML/CSS/JS propios, sin dependencias ni build. Publicado en GitHub Pages.
- Rutas limpias (carpeta/index.html); todos los enlaces son relativos.
- `404.html` y las URLs absolutas (canonical, og:image) dependen de la URL pública, definida en `SITE` del generador.
- Fuentes Inter / Inter Display (SIL OFL) autoalojadas en assets/fonts.
Diseño basado en Palmer de Westhill Studio.
